# Paws Apart demo site (Cloudflare Pages)

Static site — no build step needed on Cloudflare's side.

- `index.html` — landing page with both themes in phone frames + full-screen links
- `theme-a.html`, `theme-b.html` — the playable demos (generated by `../paws_apart_v2_source/build.py`; do not edit by hand)
- `_headers` — a few safe response headers

## Deploy (pick one)

**Dashboard, drag & drop** — Cloudflare dashboard → Workers & Pages → Create → Pages → *Upload assets* → name the project (e.g. `paws-apart`) → drop this `site` folder → Deploy.
You get `https://paws-apart.pages.dev`. Re-upload the folder to update.

**CLI** (needs Node):
```
npx wrangler login
npx wrangler pages deploy site --project-name paws-apart
```

## Update the demos
Edit files in `../paws_apart_v2_source/`, run `python build.py` — it rewrites `theme-a.html` / `theme-b.html` here — then redeploy.
